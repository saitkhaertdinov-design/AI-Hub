# AI Hub — PWA starter

Стартовая веб-оболочка AI Hub для iPhone и компьютера.

## Что уже работает
- адаптивный тёмный интерфейс;
- навигация между чатом, файлами, проектами, агентами и настройками;
- локальный демо-чат;
- выбор файлов через системный диалог;
- локальный список проектов;
- переключение светлой/тёмной темы;
- PWA manifest и service worker для установки на экран «Домой».

## Запуск
Нужен любой статический HTTPS-хостинг. Для установки PWA на iPhone открой HTTPS-адрес в Safari → «Поделиться» → «На экран Домой».

## Подключение настоящих моделей
Фронтенд ожидает backend endpoint `POST /api/chat`. API-ключи храни только на backend в переменных окружения. Сейчас файлы только выбираются и отображаются; их содержимое не отправляется в модель.

## Ограничения
Это веб-приложение, не нативный IPA и не публикация в App Store. iOS не даёт сайту бесконтрольный доступ ко всем файлам и приложениям. Агентные действия, анализ содержимого файлов и создание/сборка приложений требуют backend и отдельной реализации.

## Backend
Нужен Node.js 20+. Скопируй `.env.example` в `.env`, добавь ключи и запусти `npm start`. Перед публикацией добавь авторизацию, лимиты запросов, HTTPS и защиту от злоупотреблений.
